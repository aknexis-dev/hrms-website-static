🎓 Vidya Vihar International School Website

Frontend – Part 1

📌 Project Overview

This project is the frontend implementation of a modern school website for Vidya Vihar International School.
The goal of the project is to provide a clean, responsive, and user-friendly interface where visitors can easily access information about the school, admissions, events, and contact details.
This is Part 1 of the project, focusing only on the frontend user interface using HTML, CSS, and JavaScript.

🚀 Features

Responsive layout for desktop, tablet, and mobile
Multi-page website structure
Modern UI design
Reusable UI components using JavaScript
Navigation menu across all pages
Image gallery
Events and announcements page
Admission information
Contact page
School disclosure page
NIOS program section

🛠 Tech Stack
Technology	Purpose
HTML5	Structure of the website
CSS3	Styling and responsive design
JavaScript (Vanilla)	Dynamic components and page interactions
Google Fonts	Typography and UI enhancement
